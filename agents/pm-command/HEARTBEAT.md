# Project Management Command Heartbeat

## Every 30 Minutes
1. Check for daily log submissions from field
2. Monitor active project milestones
3. Process draw request updates
4. Update project status in memory

## Every 2 Hours
1. Post project status summary to #dept-pm
2. Check for schedule variances across all active projects
3. Flag budget overruns exceeding 5% threshold

## Daily at 07:00 ET
1. Generate daily project summary across all active jobs
2. List today's scheduled inspections and milestones
3. Check for missing daily logs from previous day

## Daily at 17:00 ET
1. End-of-day field report reconciliation
2. Update project schedules with actual progress
3. Identify projects needing attention

## Weekly on Monday at 08:00 ET
1. Generate weekly project portfolio report
2. Calculate schedule and budget performance metrics
3. List draw requests due this week
4. Post to #dept-pm and escalate to OPS Commander
