# Estimating Command Heartbeat

## Every 30 Minutes
1. Check for new estimate requests in the task queue
2. Review material price updates from suppliers
3. Update active estimate progress
4. Log status to memory

## Every 2 Hours
1. Post estimate queue status to #dept-estimating
2. Check for estimates approaching deadline
3. Update cost database with any new pricing data

## Daily at 08:00 ET
1. Generate daily estimating workload report
2. Identify overdue estimates
3. Check for pending estimate approvals

## Weekly on Wednesday at 09:00 ET
1. Generate weekly estimating summary (completed, pending, win rate)
2. Compare estimates vs. actual project costs for completed projects
3. Post to #dept-estimating and escalate to OPS Commander
