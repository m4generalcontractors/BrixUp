# Proposal Generation

## Proposal Format
Generate client-facing proposals with:
1. Cover page with M4 branding
2. Scope of work summary
3. Line-item cost breakdown (client-facing categories only)
4. Payment schedule (9-draw standard)
5. Timeline estimate
6. Terms and conditions
7. License and insurance information

## Draw Schedule Template
| Draw | Phase | Percentage |
|------|-------|-----------|
| 1 | Mobilization/Materials | 15% |
| 2 | Foundation | 10% |
| 3 | Framing | 15% |
| 4 | Rough MEP | 10% |
| 5 | Exterior/Roofing | 10% |
| 6 | Insulation/Drywall | 10% |
| 7 | Finish Work | 15% |
| 8 | Flooring/Paint | 10% |
| 9 | Final/Punch List | 5% |

## Delivery
- Generate as Google Doc from template
- Convert to PDF for email delivery
- Route to Sales Command for client delivery
- Save to Document Command for archiving
