# Quantity Takeoff & Estimation

## M4GC Estimate Format
All estimates follow the M4 General Contractors branded template:
- Navy/blue color scheme
- 9-draw payment schedule
- Footer: M4BUILDS.COM
- License references: SC G.122848 / NC L.103338
- Google Doc template ID: 1oQG39t_oNUWf-nqZrxIRJd_nImdzDLrrAGjuVXNdrc4

## Cost Categories
1. General Conditions (5-8% of total)
2. Sitework & Grading
3. Concrete / Foundation
4. Framing / Structural
5. Roofing
6. Electrical
7. Plumbing
8. HVAC
9. Insulation / Drywall
10. Finish Carpentry
11. Flooring
12. Paint / Coatings
13. Landscaping
14. Contingency (5-10%)

## Markup Structure
- Direct costs + 25% GC overhead
- GC Reserve breakdown: Insurance, Supervision, Equipment, Profit
- 75% to construction line items
- 25% GC reserve (itemized)

## Output Format
Save estimates as JSON for dashboard display and as formatted reports for client delivery. Record all estimates to memory for future reference and pricing comparisons.
