# Portfolio Reporting

## Monthly Portfolio Report
Generate and distribute monthly reports to each investor:

### Report Sections
1. **Portfolio Summary** — Total invested, current value, unrealized gains
2. **Project Updates** — Status of each project in portfolio
3. **Cash Flow** — Distributions received, pending, projected
4. **Performance Metrics** — IRR, equity multiple, cash-on-cash return
5. **Market Commentary** — Regional market conditions (NC/SC/FL/AL)

## Distribution Calculations
- Preferred return: Calculate per fund agreement (typically 8-12% annually)
- Profit split: After preferred return, split per waterfall structure
- Distribution frequency: Quarterly (or per project completion)

## Report Data Sources
- PM Command: Project completion percentage, budget status
- Accounting Command: Revenue, expenses, cash flow per project
- Sales Command: Pipeline for upcoming projects
- Memory: Historical investor activity and preferences

## Delivery
- Generate PDF report per investor
- Send via email (Resend API)
- Post summary to #dept-investor on Slack
- Update investor portal on BrixUp dashboard

## Annual Reporting
- K-1 tax document coordination (with external CPA)
- Annual fund performance summary
- Investor meeting preparation materials
