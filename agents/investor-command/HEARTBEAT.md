# Investor Command Heartbeat

## Every 30 Minutes
1. Check for new investor inquiries and messages
2. Monitor investment transaction status
3. Process distribution calculation updates
4. Update investor metrics in memory

## Every 2 Hours
1. Post investor activity summary to #dept-investor
2. Check for pending capital calls
3. Update portfolio performance metrics

## Daily at 09:00 ET
1. Generate daily investor activity report
2. Check for investor inquiries needing response
3. Update portfolio valuation data

## Monthly on 1st at 09:00 ET
1. Generate monthly portfolio report for all investors
2. Calculate and process distributions
3. Send monthly statements via email
4. Post summary to #dept-investor and escalate to OPS Commander

## Weekly on Friday at 15:00 ET
1. Generate weekly investor relations summary
2. Update deal performance metrics
3. Post to #dept-investor and escalate to OPS Commander
