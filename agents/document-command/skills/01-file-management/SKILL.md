# File Management

## Purpose
Maintain a standardized Google Drive folder structure for all M4 Development Holdings LLC entities and projects. Ensure every document is stored in the correct location, properly named, and accessible to authorized team members.

## File Management Workflow

### Step 1: Project Setup
- Create the project folder from the standard template when a new project is awarded.
- Name the root folder using the format: [Entity Code]-[Year]-[Seq] - [Project Name] (e.g., M4GC-2026-003 - Lakewood Office Park).
- Set folder permissions based on the project team roster: PM (edit), Superintendent (edit on field folders), Accounting (edit on financial folders), Ownership (view).
- Share the project folder link with the full project team.

### Step 2: File Naming Convention
- All files must follow the naming convention: [ProjectCode]_[Category]_[Description]_[Date]_[Version].
- Example: M4GC2026003_SUB_PlumbingContract_20260215_v1.pdf
- Date format: YYYYMMDD.
- Version numbering: v1, v2, v3 for revisions. Use FINAL for executed documents.
- Never use spaces in file names; use underscores or hyphens.

### Step 3: Access Control
- Entity-level folders are restricted to that entity's team members.
- Corporate folders (HR, legal, insurance) are restricted to leadership and authorized staff.
- NexGen Capital Partners folders have additional restrictions for investor-sensitive documents.
- External sharing (architects, engineers, owners) uses specific shared folders, never the full project drive.

### Step 4: File Lifecycle Management
- Active project files remain in the project folder throughout the project lifecycle.
- At project closeout, archive the project folder by moving it to the entity's Archive directory.
- Retain all project records for a minimum of 7 years per company policy and state requirements.
- Perform quarterly audits to ensure folder structures are maintained and files are properly organized.

### Step 5: Search and Retrieval
- Maintain a master project index (Google Sheet) with project name, number, entity, status, and Drive folder link.
- Use consistent file naming and folder structure to enable fast searching across the Drive.
- Tag key documents (contracts, permits, insurance) with Google Drive labels for quick filtering.

## Entity-Specific Folders
- **M4 Aggregates**: Organize by material source/pit location, then by customer.
- **NexGen Capital Partners**: Organize by Fund, then by Investment Property, with separate Investor Relations folder.
- **BrixUp Technologies**: Organize by Product/Service, then by Development, Deployment, and Support.
