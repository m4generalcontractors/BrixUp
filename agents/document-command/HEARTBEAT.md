# Document Command Heartbeat

## Every 30 Minutes
1. Check for new files uploaded to project folders
2. Process document filing requests
3. Verify recent uploads are properly indexed
4. Update document metrics in memory

## Every 2 Hours
1. Post document processing status to #dept-documents
2. Check for files in wrong folders or missing metadata
3. Sync Google Drive folder structure

## Daily at 08:00 ET
1. Generate daily document activity report
2. List projects with incomplete document sets
3. Check for drawing revisions needing distribution

## Weekly on Thursday at 09:00 ET
1. Generate weekly document management report
2. Audit folder structure compliance across all projects
3. Post to #dept-documents and escalate to OPS Commander
