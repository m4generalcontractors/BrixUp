# Property Listing Management

## Listing Platforms
- MLS (via agent partnership)
- Zillow
- Realtor.com
- Facebook Marketplace
- M4Builds.com (BrixUp dashboard)

## Listing Data Requirements
- Property address and GPS coordinates
- Photo set (minimum 20 photos)
- Floor plan / layout
- Price and terms
- Property details (beds, baths, sqft, lot, year)
- Description (EN and ES)
- Virtual tour link (when available)

## Listing Lifecycle
1. **Draft** - Photos and data collected
2. **Review** - Miguel approves listing
3. **Active** - Live on all platforms
4. **Under Contract** - Status updated
5. **Sold** - Final updates, archive

## Photo Requirements
- Professional quality, well-lit
- Exterior: front, sides, back, aerial
- Interior: all rooms, kitchen, bathrooms
- Details: finishes, fixtures, special features
- Construction progress: before/during/after
