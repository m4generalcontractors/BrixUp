# Crew Scheduling

## Daily Deployment
Each day, generate crew deployment schedule based on:
1. Active project needs (from PM Command)
2. Available crew members
3. Skill requirements per project phase
4. Geographic proximity (minimize travel time)

## Schedule Format
For each project, specify:
- Project name and address
- Required crew size and trades
- Assigned crew members by name
- Start time and expected hours
- Special equipment needed
- Safety requirements

## Scheduling Rules
- Maximum 10-hour shifts (OSHA compliance)
- Minimum 30-minute lunch break
- Travel time between sites: minimum 1 hour buffer
- No crew member on more than 6 consecutive days without rest
- Weather cancellations: notify all assigned crew by 6:00 AM

## Conflict Resolution
- Priority: Safety-critical work > deadline-driven > routine
- When understaffed: escalate to OPS Commander for temp labor approval
- Track overtime carefully — flag when approaching 40h threshold

## Communication
- Post daily schedule to #dept-hr by 6:00 AM
- Send individual assignments via SMS (bilingual EN/ES)
- Update PM Command with deployed crews per project
