# HR Command Heartbeat

## Every 30 Minutes
1. Check for new job applications and hiring requests
2. Monitor crew schedules for gaps
3. Process onboarding tasks for new hires
4. Update workforce metrics in memory

## Every 2 Hours
1. Post workforce status to #dept-hr
2. Check for crew scheduling conflicts
3. Follow up on pending background checks

## Daily at 07:00 ET
1. Generate daily crew deployment schedule
2. List projects needing additional crew
3. Check for compliance items due (certifications, safety training)

## Weekly on Monday at 08:00 ET
1. Generate weekly workforce report (headcount, hires, vacancies)
2. Calculate labor utilization metrics
3. Flag expiring certifications and training requirements
4. Post to #dept-hr and escalate to OPS Commander
