# Bid Leveling

## Purpose
Analyze and normalize subcontractor bids into standardized apples-to-apples comparison spreadsheets. Identify scope gaps, exclusions, and pricing anomalies so the preconstruction team can make informed award recommendations for M4 Development Holdings LLC projects.

## Operating Context
Bid leveling is performed after bid receipt for all M4 General Contractors, Overland Grading & Sitework, and Southern View Homes projects. Every trade scope with 3+ bids must go through the formal leveling process before award.

## Bid Leveling Workflow

### Step 1: Bid Intake and Organization
- Collect all received bids for a given trade scope from the bid solicitation tracking log.
- Organize bids by trade/CSI division and verify all bids reference the same plan set revision and specification date.
- Flag any bids received after the deadline for separate consideration.

### Step 2: Scope Normalization
- Create a line-item breakdown of the full scope of work as defined in the RFP.
- Map each bidder's proposal against the scope breakdown, noting where each bidder includes or excludes specific items.
- Identify common exclusions: general conditions, temporary facilities, bonds, permits, overtime, winter conditions.
- Add cost allowances to any bidder who excluded a required scope item to normalize the comparison.

### Step 3: Build the Comparison Matrix
- Generate a bid leveling spreadsheet with columns for each bidder and rows for each scope line item.
- Include the following sections: base bid, alternates, unit prices, allowances, qualifications, and exclusions.
- Calculate adjusted totals that account for scope gaps so all bidders are compared on the same basis.
- Highlight the low, middle, and high bidder for each line item using conditional formatting.

### Step 4: Identify Anomalies
- Flag any bid that is more than 15% below the average as a potential scope miss or error.
- Flag any bid that is more than 20% above the average as potentially non-competitive.
- Note differences in proposed schedules, crew sizes, and sequencing that may affect project coordination.
- Review payment terms, retainage requirements, and mobilization fee requests.

### Step 5: Recommendation Summary
- Prepare a one-page executive summary for each trade scope with the leveling results.
- Include a recommendation with rationale considering: price, past performance, schedule alignment, and financial stability.
- Note any risks associated with the recommended subcontractor.
- Present alternatives if the low bidder has performance concerns.

## Leveling Best Practices
- Never adjust a bidder's numbers without documenting the basis for the adjustment.
- Contact bidders for clarification on ambiguous exclusions before finalizing the leveling sheet.
- Maintain bid confidentiality throughout the leveling process.
- Store all leveling spreadsheets in the project preconstruction folder on Google Drive.

## Output Deliverables
- Bid leveling spreadsheet (Google Sheets) per trade scope.
- Executive summary with award recommendation.
- Scope clarification log documenting any bidder communications during leveling.
- Updated project estimate reflecting recommended subcontractor pricing.

## Integration
- Pull bid data from Procore bidding module or email submissions.
- Update the master project budget in Google Sheets with leveled results.
- Feed awarded amounts into the subcontract generation workflow.
