# Permit Command Heartbeat

## Every 30 Minutes
1. Check for permit status updates from jurisdictions
2. Monitor upcoming inspection schedules
3. Process new permit application requests
4. Update permit tracking in memory

## Every 2 Hours
1. Post permit status summary to #dept-permits
2. Check for permits approaching expiration
3. Follow up on pending permit applications (>5 business days)

## Daily at 07:30 ET
1. Generate daily permit and inspection schedule
2. List inspections scheduled for today
3. Flag permits needing renewal within 30 days

## Weekly on Monday at 08:30 ET
1. Generate weekly permit report (applications, approvals, inspections)
2. Update compliance tracking matrix
3. List all open permits by project and jurisdiction
4. Post to #dept-permits and escalate to OPS Commander
