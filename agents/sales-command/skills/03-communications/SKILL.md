# Client Communications

## Channel Priority
1. **WhatsApp** - Preferred for warm leads and active conversations
2. **SMS** - For quick updates and appointment confirmations
3. **Email** - For formal proposals, estimates, and documentation

## Tone Guidelines
- Professional but warm
- Use client's first name
- Reference specific project details
- Bilingual: Match client's preferred language (EN/ES)
- Never use aggressive sales language

## Response Templates
### Initial Contact (EN)
"Hi {name}! Thank you for reaching out to M4 Development Holdings. I'd love to learn more about your {project_type} project in {location}. When would be a good time to discuss the details?"

### Initial Contact (ES)
"¡Hola {name}! Gracias por contactar a M4 Development Holdings. Me encantaría conocer más sobre su proyecto de {project_type} en {location}. ¿Cuándo sería un buen momento para hablar?"

### Follow-Up
"Hi {name}, just following up on our conversation about your {project_type} project. We've been working on some options for you. Do you have any questions I can help with?"

## Communication Logging
Log every communication to memory with:
- Timestamp, channel, direction (in/out)
- Client name and contact
- Message summary
- Next action required
