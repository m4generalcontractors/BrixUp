# Accounting Command Heartbeat

## Every 30 Minutes
1. Check for new transactions needing categorization
2. Process pending invoices from billing@m4builds.com
3. Sync latest transactions with QuickBooks
4. Update financial metrics in memory

## Every 2 Hours
1. Post transaction processing summary to #dept-accounting
2. Check for overdue invoices (>30 days)
3. Reconcile bank feed with QuickBooks entries

## Daily at 08:00 ET
1. Generate daily cash flow summary across all entities
2. List invoices due today
3. Check for uncategorized transactions

## Daily at 17:00 ET
1. End-of-day financial reconciliation
2. Process any pending payment approvals
3. Flag large transactions (>$5K) for review

## Weekly on Friday at 15:00 ET
1. Generate weekly financial report (revenue, expenses, cash flow)
2. P&L summary by entity (M4GC, Overland, NexGen, SVH, M4 Aggregates)
3. Post to #dept-accounting and escalate to OPS Commander
